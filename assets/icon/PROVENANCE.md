# RAVE Performance Instrument icon provenance

`rave-instrument-icon.svg` is original artwork created for this repository in
2026 by RAVE Performance Instrument contributors. It depicts an abstract
latent portal: a rounded graphite field, turquoise portal ring and crossbars,
and an asymmetric amber control point. The geometry was drawn specifically for
this project; it was not traced from, copied from, or derived from RAVE, IRCAM,
or any third-party mark.

The project owner explicitly authorized this original project-owned icon as a
substitution after rejecting use of the official RAVE mark. The source and all
checked-in derivatives are licensed under the permissive MIT license in
[`LICENSE.md`](LICENSE.md). This license applies to this artwork only and does
not grant rights to RAVE, IRCAM, or their trademarks.

## Canonical source and derivatives

The sole canonical artwork source is `rave-instrument-icon.svg`. The PNG files
`rave-instrument-icon-{16,32,64,128,256,512,1024}.png` are deterministic
square RGBA derivatives. The set covers 16 px and 32 px small/HiDPI use,
through 1024 px packaging and high-density use. JUCE consumes the 32 px and
1024 px variants to generate each macOS bundle's `Icon.icns`; the SVG is also
embedded into each editor through JUCE BinaryData and copied to supported
macOS bundle resources.

`SHA256SUMS` pins every checked-in PNG. It is a reproducibility receipt, not a
claim that a different SVG renderer version will produce identical bytes.
